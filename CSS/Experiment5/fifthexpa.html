Various Reference CSS Color

Named Color: Using predefined color keywords like red, blue, or green.
Hexadecimal Color: Specifying colors with a # followed by six hexadecimal digits representing red, green, and blue (e.g., #3498db).
RGB Color: Using the rgb() function with red, green, and blue values ranging from 0 to 255 (e.g., rgb(46, 204, 113)).
RGBA Color: Like rgb() but with an alpha channel for opacity ranging from 0 (transparent) to 1 (opaque) (e.g., rgba(231, 76, 60, 0.6)).
HSL Color: Using hue (0-360 degrees), saturation (%), and lightness (%) to define colors (e.g., hsl(39, 100%, 50%)).
HSLA Color: Same as hsl(), but with an alpha (opacity) value from 0 to 1 (e.g., hsla(300, 100%, 25%, 0.7)).
CSS Variable: Using a custom property defined with --name and accessed via var(--name) for reusable colors (e.g., var(--custom-color)).
